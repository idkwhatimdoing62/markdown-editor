# 示例文档：Markdown 编辑器

这份文档用来试功能：切段落编辑、目录、专注模式、导出 HTML/PDF 都可以拿它试。

## 混合编辑

文档始终可编辑，只有光标所在的段落展开成源码，其余内容保持排版。点一下别的块就切换编辑对象，视线不会被满屏的标记符号打断。

- 有序列表会自动续写序号
- 任务列表续写为未勾选

1. 第一项
2. 第二项
3. 第三项

- [x] 已完成的事项
- [ ] 待办的事项

## 排版元素

**加粗**、*斜体*、`行内代码`、[链接](https://github.com/idkwhatimdoing62/markdown-editor)、脚注[^1]。

> 引用块：慢的根源通常不在渲染，而在「每次按键都重算整篇」。

| 场景 | 优化前 | 优化后 |
| --- | --- | --- |
| 2MB 文档全帧渲染 | 135 ms | 约 2 ms |
| 每次按键的临时分配 | 3–4×2MB | 1×2MB |
| 纯 ASCII 导出 HTML | 约 36 MB | 1 MB 以内 |

```bash
# 代码块里的注释会按语言弱化显示
for block in $(seq 1 200); do
    printf '%s\t%s\n' "$block" "$(measure_block "$block")"   # 超过 0.5ms 记为热点
done
```

## 快捷键

按 `F7` 呼出章节目录，`F8` 进入专注模式（当前段落以外置灰），`F9` 打字机模式，`Esc` 收起当前段落的编辑区。

[^1]: 脚注也支持。
