# Changelog

## [0.1.40] - 2026-09-18

### Changed

- 空工作区改为垂直居中的紧凑分组：标题 24px，按钮行按 240×32 显式分配宽度并居中，拖放提示改用等宽档 11px。此前用 `horizontal_centered`（justified 布局）会占满面板剩余高度，把按钮行推到面板底部、与标题拉开一整屏距离。

### Fixed

- 「设为 Markdown 默认应用…」打开的是文件资源管理器而不是「设置」：该命令交给 `explorer.exe` 执行，而 Explorer 把命令行参数按文件系统路径解析，`ms-settings:` 解析不出路径时退化成打开一个文件夹窗口（「文档」）。改用 `ShellExecuteW("open", …)` 走 Shell 的协议处理器，URI 里的应用名转义改为由 `REGISTERED_APP_NAME` 派生，并补上返回值 ≤ 32 的失败判定与状态栏提示。

## [0.1.39] - 2026-09-17

### Changed

- 章节目录默认隐藏：F7 或「视图」菜单呼出，写作时少一块常驻干扰；标签栏与目录面板改用窗口底色。
- 代码块阅读态与导出 HTML 对齐：去掉盒内描边，语言名移到右上角小标签并按 mono 档 11px 显示（与导出 CSS 的 `pre[data-language]` 同档）。
- 代码块注释按语言弱化显示：识别 shell / Python / YAML 的 `#`、C 系 / Rust / Go 的 `//`、SQL / Lua 的 `--`、汇编的 `;`；字符串内部的注释符与词中间的符号不误判，未识别的语言保持字面色。
- 引用块改用中性阶文字与中性竖线；二级标题去掉多余的分割线，层级交给字号与留白。

### Fixed

- 导出 HTML 的 Mermaid 图表从不渲染：引导脚本排在 `<head>` 里，早于 body 解析执行，`querySelectorAll` 拿到的永远是空集合；现在移到 `</body>` 之前。
- 导出 HTML 里带百分号转义或查询串的图片（`图%20一.png`、`a.png?v=2`）解析不到文件、静默退化成 `src="#"`：预览与导出现在共用同一套 URL → 路径归一规则。
- 目录跳转错位：被编辑器替换（或被编辑区间吞掉）的块不推进渲染序号，点「第二节」会滚到「第三节」或干脆不动；序号现在从块列表推导，与块的呈现形态无关。
- 查找面板打开期间无法编辑其他段落：搜索命中被逐帧重新锚定，用户点开的段落立刻被拉回；现在只在显式导航（打开查找、修改查询、上/下一项）后锚定一次，后台结果到达的那一帧再落位。
- 关闭确认弹窗弹着时点其他标签的 ✕ 会丢掉点击；若此时当前标签正好已保存（例如刚 Ctrl+S），还会把当前标签关掉。现在弹窗期间不再接受叠加的关闭请求，且保存会兑现待处理的关闭确认。
- 专注模式下代码注释的对比度跌破 4.5:1（浅色实测 3.31:1）：注释色改为由正文色与代码底色派生，并按基线收敛弱化幅度，对比度用例覆盖专注模式下的输入。

## [0.1.38] - 2026-09-17

原生 egui 重写合入主线。版本号由 0.1.25 上调为 0.1.38，避开 WebView 预览主线已发布并占用的 0.1.24–0.1.37。

### Changed

- 解析与全文搜索迁到后台 worker（ADR-0004）：源码、解析树与文档状态由与界面无关的 core 持有，解析结果带 revision 校验后才安装，旧结果不会覆盖新内容；解析追赶期间文档仍按上一版解析排版，只有正在编辑的段落切回源码编辑，不再整篇退化为源码视图。
- 编辑中的段落保留块级标记：`#`、`-`/`*`/`+`、`1.`、`- [ ] ` 与 `>` 以弱化颜色显示（不再隐形）；成对行内标记 `**`、`_`、`` ` ``、`~~` 同样改为弱化显示、不再隐形——编辑态所见即源码，渲染效果（加粗、行内代码样式、引用框等）只出现在阅读态的非活动块。
- 编辑中的围栏代码块保留代码盒外观（底色、边框、圆角），markdown 语法照常展示：` ``` ` 围栏记号与语言名以弱化色显示，代码内容按字面文本渲染、不受标记规则影响（shell 注释 `#`、普通 `- ` 行、`**` 不会再变淡或隐形）；代码块内按 Enter 不再误续写列表标记。引用块编辑时不套用引用框与强调条，回到朴素源码。
- 编辑区与预览区字体真正统一为 JetBrains Mono（英文）+ 霞鹜文楷轻便版（中文）：修复比例字体槽仍以 egui 内置 Ubuntu-Light 开头导致英文字体不生效的问题；代码块、UI 界面、标题同步换用新字体栈，中文粗体/标题使用霞鹜文楷 Medium 字重。
- 强调（`*斜体*`）现在真实渲染为斜体：内嵌 JetBrains Mono Italic / Bold Italic 并注册独立字体族（egui 的 `italics` 标记此前是空实现）；HTML 导出移除 `font-synthesis:weight` 允许浏览器合成斜体。
- 预览标题颜色修复：`override_text_color` 不会影响标题使用的 `strong_text_color()` 槽位，标题此前一直渲染为 egui 默认深灰而非主题标题色。
- 中文标点排版：`—— …… “” ‘’ ·` 改为霞鹜文楷全角渲染（JetBrains Mono 自带的半宽字形不再拦截），英文语境保持半宽；行内代码增加主题底色，与围栏代码块视觉呼应；链接悬停显示手型光标。
- Markdown 解析不再为整个事件流做冗余克隆：Builder 改为借用事件，长文档每次按键的临时分配从约 3-4 倍文档大小降回解析产物本身。
- 全文搜索改为 Horspool 坏字符跳跃扫描，自然文本上亚线性；ASCII / 非 ASCII 查询统一走同一条匹配路径（ASCII 字母一律忽略大小写）。
- 移除不再有入口的主题导入代码（`.css` / 主题 `.json` / `.zip`）与 `zip` 依赖；已保存的主题仍照常加载，内置主题不受影响。
- 默认主题更换为内置「专注写作」：素净纸白配色、无装饰色块，标题去样式化，正文 16.5px / 行高 1.7 / 780px 窄栏；字体仍为 JetBrains Mono（英文）+ 霞鹜文楷轻便版（中文）。移除内置少数派经典主题与 `assets/sspai.css`。

### Added

- Typora 式列表续写：在列表/任务列表/有序列表行尾按 Enter 自动续写标记（有序序号递增、缩进保留、任务列表续写为未勾选）；在空列表项上再按 Enter 退出列表。
- 专注模式（F8）置灰当前段落以外的内容，视线锚定写作位置。
- Ctrl+鼠标滚轮缩放正文字号（与 Ctrl+= / Ctrl+- 一致）。
- 窗口标题跟随当前文档，未保存时以 · 标记（任务栏 / Alt+Tab 可辨）。
- 字号缩放快捷键：Ctrl+= 放大、Ctrl+- 缩小、Ctrl+0 恢复主题默认字号。

### Performance

- 标签栏、窗口标题与草稿自动保存共用的「未保存」判定改为按（标签、版本、磁盘快照）缓存，长文档不再每帧对整篇文档做字节比较。
- 草稿会话只在内容真正变化时重写：脏标签闲置时不再每个自动保存周期重写同一份草稿。
- 长文档视口剔除优先复用已测块高，不再为不可见块重新扫描源码估算高度；搜索命中只换算一次字符↔字节偏移，且只测量所在段落内的切片。
- 没有文件标签的窗口不再保留 350ms 外部修改轮询定时器；空闲窗口不再被周期性唤醒。
- 长文档预览启用视口剔除：只布局可见区域附近（约 1.5 个视口）的块，2MB 文档全帧渲染从约 135ms 降至约 2ms；每标签独立缓存块高度，宽度/字号变化自动失效。
- 编辑区语法隐藏标记的 code-span 判定由逐分隔符全文扫描改为二分定位，复杂度 O(n²)→O(n log n)。
- 状态栏字符/行数统计按标签+版本缓存；外部修改探测不再每帧克隆磁盘快照；脏检查改为无分配的字节比较。
- HTML 导出按内容决定字体内嵌：纯 ASCII 文档跳过约 26MB 的霞鹜文楷，体积从约 36MB 降至 1MB 以内；含中文文档字体不变。

### Fixed

- 多块脚注定义导致 `blocks()` 与 `block_ranges()` 失去一一对应、其后所有块源码区间错位的问题；此前整篇文档会静默退化为全文源码编辑模式。
- 磁盘文件为 0 字节的标签会导致整个草稿会话保存失败的问题：此类「空文件 + 首次输入」的标签此前永远无法进入崩溃恢复。
- 保存不再悄悄丢失 UTF-8 BOM：读取时剥掉的字节顺序标记在保存与覆盖保存时补回。
- 磁盘文件被外部删除时保存不再报「找不到文件」，而是按外部修改冲突处理，可直接选择覆盖保存或另存为。
- 保存失败不再把半成品 `.tmp` 留在用户目录；保存成功后按「文件名精确匹配 + 60 秒冷却期」清扫文档目录中本应用残留的 `.tmp`/`.bak` sidecar（用户自己的 `.bak` 不受影响）。
- 导入主题 CSS 的 `@media` 等嵌套 at 规则递归无深度上限，构造性主题可触发栈溢出崩溃：现在嵌套深度封顶 32 层。
- 窗口关闭批准改为一次性消费，异常路径下窗口存活时新出现的未保存内容仍会触发确认。
- 原始 HTML 图片 `width="50%"` / `width="720px"` 现在也会附加 `max-width:100%` 保护。
- 注册表 ProgID 键路径统一由 `PROG_ID` 常量拼接，消除字面量与常量漂移。
- 单实例 IPC 增加用户级令牌：监听端只接受携带本用户令牌的请求（伪造请求收到否定应答并立即失败），端口冲突时也不会把文件路径交给无关进程。
- 协议相对 URL（`//host/…`）与 UNC 路径（`\\host\share`）不再被当作普通相对链接交给系统打开，避免点击后触发网络位置访问。
- 导出 HTML 的链接消毒可被前导空白 / 实体编码的可执行协议（` javascript:`、`&#x0A;javascript:`）绕过的问题；预览内点击打开链接同样受益。
- 段落点击总是打开第一个链接的问题：现在按点击位置精确命中对应链接。
- 后台解析 / 搜索线程意外退出时界面永久 16ms 重绘并停在「正在解析」的问题：现在自动降级为同步解析并提示。
- 导入的主题 CSS 中 `font-size` 以多字节字符结尾会导致导出 panic。
- 保存提示与状态栏时间显示为 UTC 的问题（Windows 使用本地时间）。
- `refresh_status` 对带 BOM 文件误报「已修改」；保存语义与脏检查统一。
- 导出内嵌本地图片增加 32MB 上限，防止单个超大文件耗尽内存。
- 打开文件失败、后台任务关闭等不再错误地复用「保存失败」状态。
- 另存为新路径后，旧路径解除文件监听并清理探测状态。
- 清理辅助窗口崩溃残留的 `draft-window-<pid>.json`；`.gitignore` 补充 `tmp/` 与根目录演示 zip。

## [0.1.23] - 2026-08-31

### Fixed

- 使用操作系统文件变更通知及时发现 Agent 或其他程序对已打开 Markdown 的修改；通知丢失时保留轮询兜底。
- 即使外部改写没有改变文件时间戳和长度，也会读取并进入现有的稳定等待、自动重载或冲突流程。
- 从多标签草稿恢复文件后继续注册外部文件通知，不再遗漏恢复出来的标签。
- 预览搜索按渲染后的可见文本判断结果，避免把链接 URL 等 Markdown 源码语法误报为预览匹配。

### Added

- 阅读和分栏模式支持预览区文字搜索；搜索会先定位源码对应位置、加载虚拟预览块，再使用 WebView 原生匹配高亮，支持 Enter / Shift+Enter 切换结果。
